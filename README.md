# gen-guestid-test

ตัวตรวจเลเวลบัญชี guest (Guest Level Checker) มีสองโหมด

## 1. หน้าเว็บ (แนะนำ)

```bash
cd level-ck
pip install -r requirements.txt
python webapp.py        # เปิด http://localhost:3000
```

- กรอกบัญชีในหน้าเว็บ บรรทัดละ 1 บัญชี ในรูปแบบ `UID:รหัสผ่าน`
- ตรวจไม่เกิน 200 บัญชีต่อครั้ง (ปรับได้ด้วย `MAX_ACCOUNTS`)
- ไม่มีการเขียนไฟล์ลงดิสก์: ผลลัพธ์อยู่ในหน่วยความจำและเบราว์เซอร์ของคุณ
  เซิร์ฟเวอร์ไม่ส่งรหัสผ่านกลับใน response — ไฟล์ผลลัพธ์สร้างในเบราว์เซอร์ตอนกดดาวน์โหลด
- ปลายทางที่ใช้ตรวจเลเวลถูกส่งออกเป็น response header `Cache-Control: no-store`
  เพื่อไม่ให้แคชผลที่มีข้อมูลบัญชี

## 2. โหมดบรรทัดคำสั่ง (เดิม)

```bash
cd level-ck
python app.py           # อ่าน accounts.txt แล้วเขียนผลลง Results/
```

## 3. เซิร์ฟเวอร์ตัวอย่าง (demo)

ไว้ทดสอบหน้าจอโดยไม่ต้องมีเซิร์ฟเวอร์ตรวจของตัวเอง และไม่ต้องส่งบัญชีจริงออกไป
ข้อมูลที่ตอบกลับเป็นค่าสังเคราะห์จาก UID (`DEMO-xxxx`, เลเวล 0–30, ภูมิภาค `DEMO`)

```bash
cd level-ck
python demo_api.py &        # 127.0.0.1:8899
DEMO_MODE=1 \
JWT_ACCOUNT_API=http://127.0.0.1:8899/token \
INFO_API=http://127.0.0.1:8899/info \
python webapp.py
```

เมื่อตั้ง `DEMO_MODE=1` หน้าเว็บจะขึ้นแถบเตือนว่าเลเวลเป็นข้อมูลสาธิต
(ถ้าไม่ตั้ง เลเวลที่ได้จะมาจาก endpoint จริงตามปกติ)

## การตั้งค่าปลายทางตรวจสอบ

| ตัวแปร | ค่าเริ่มต้น | ใช้ทำอะไร |
| --- | --- | --- |
| `JWT_ACCOUNT_API` | `https://ayan-jwt-token-gen.vercel.app/token` | ยืนยันบัญชีและขอ account id |
| `INFO_API` | `https://ayan-ob55-info.vercel.app/info` | ดึงชื่อ เลเวล และภูมิภาค |
| `PORT` | `3000` | พอร์ตของหน้าเว็บ |
| `MAX_ACCOUNTS` | `200` | จำนวนบัญชีสูงสุดต่อการตรวจหนึ่งครั้ง |

ทั้งสองโหมดใช้บริการภายนอกสองรายการข้างต้นในการตรวจเลเวล
ถ้าต้องการให้ข้อมูลออกจากเครื่องน้อยที่สุด ให้ชี้ตัวแปรทั้งสองไปยังเซิร์ฟเวอร์ของคุณเอง
