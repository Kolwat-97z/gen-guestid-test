Guest Level Checker

กรอกบัญชีในเบราว์เซอร์ — รหัสผ่านไม่ถูกบันทึกลงดิสก์ และไม่ถูกส่งกลับจากเซิร์ฟเวอร์

ตรวจได้สูงสุด {{ max_accounts }} บัญชีต่อครั้ง · บัญชีซ้ำ (UID เดียวกัน) จะถูกนับครั้งเดียว

UID ที่กรอก Account ID ชื่อ เลเวล ภูมิภาค หมวด / สถานะ

สร้างในเบราว์เซอร์ของคุณเอง ยังไม่มีข้อมูลใดถูกบันทึกไว้ที่เซิร์ฟเวอร์

ปลายทางที่ใช้ตรวจสอบ

การตรวจเลเวลยังต้องเรียกบริการภายนอกสองรายการนี้:
ตรวจบัญชี: {{ account_api }}
ข้อมูลเลเวล: {{ info_api }}
เปลี่ยนปลายทางได้ด้วยตัวแปร JWT_ACCOUNT_API และ INFO_API ก่อนเริ่มเซิร์ฟเวอร์
